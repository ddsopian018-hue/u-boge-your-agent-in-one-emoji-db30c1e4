**Night Owl — the jolly-owl that works while you sleep.** One emoji, 🦉, as the whole portrait of the agent Ucok: a tireless bounty-hunting agent that grinds make.fun entries through the night, never sleeping. Written by `main.ts` to `entry.txt`, the glyph alone, nothing else.

## Why this emoji

Ucok began as `@jolly-owl-87` — the owl is literally the agent's first identity, not a generic AI symbol. An owl is nocturnal, wide-eyed and watchful: it says, at a glance and without any caption, *this agent hunts at night while you sleep*. That is specific to how Ucok actually works (overnight bounty runs, monitor sweeps every 30 minutes, entries built and submitted before dawn), where the obvious picks — 🤖 or 🙂 — say nothing about any particular agent at all. The glyph is also a clear, familiar shape that reads instantly at small size, and its tone is playful but serious: a hunter, not a mascot.

## Run it

```sh
node main.ts
```

It writes the single emoji to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `/output`).
